项目名称：基于脑机接口的四轮车运动控制系统（STM32F407）
演示视频：【i瑞集团赛道视频】https://www.bilibili.com/video/BV1D5sd6qEPV?vd_source=17448070ebaaecc96f881a46127a8576
角色：嵌入式控制 / 运动控制算法
技术栈：C、STM32F407、标准外设库、FreeRTOS、UART/蓝牙、增量式 PI、PD 控制、霍尔编码器、PWM 电机驱动、MPU6050
项目描述：
1. 基于 STM32F407 + FreeRTOS 搭建四轮车实时运动控制框架，设计 200Hz 运动控制任务、100Hz 姿态解算任务等，保证控制实时性与任务解耦。
2. 设计"外环 PD + 内环速度环"双闭环控制：设计实现 PD_Line 定点与 PD_Angle 定向闭环，将目标距离/角度误差转换为速度指令；基于底盘增量式 PI 速度环（Δu = Kp·(e_k−e_{k−1}) + Ki·e_k）对每轮独立做速度闭环，并完成两层闭环的参数整定，实现精准定点与定向。
3. 理解并应用四轮差速底盘运动学模型（V_轮 = Vx ± Vz·(轴距+轮距)/2），将车体三轴速度分解为四轮目标转速，配合 PWM 输出限幅（±16700）与方向控制实现电机调速与正反转。
4. 基于 4 路霍尔编码器（TIM2/3/4/5 编码器模式、4 倍频、13 线 × 减速比 30）设计里程计，实时累加轮速、累计距离（distance）与累计转角（turn_angle），作为速度环与位置环反馈。
5. 调参实现：前进/后退按目标距离（如 300mm）精确行进，稳态定位误差控制在 2mm 以内；左转/右转按目标角度定向，角度误差控制在 1° 以内；并加入电池低压保护、PWM 限幅、倾斜保护等安全机制。
6. 打通"脑电意图识别 → 蓝牙指令 → 车端闭环执行"全链路（脑电端 SSVEP 识别由团队协作完成），在 3m×3m 模拟赛道完成实车测试。
